# Number Guessing System 

This is a simple number guessing game I made using Python.

In this game, the computer picks a random number between 1 and 100, and the player has to guess it.

If the guess is wrong, the game tells whether the number is too high or too low. It also counts the number of attempts taken to guess the correct number.

## Features

- Random number between 1 and 100
- Hints for each wrong guess
- Counts the number of attempts
- Checks for invalid input
- Option to exit the game anytime
- Simple welcome screen

## How to Run

1. Make sure Python is installed on your computer.
2. Download or clone this repository.
3. Open the project folder in VS Code.
4. Run the Python file:

   `python main.py`
